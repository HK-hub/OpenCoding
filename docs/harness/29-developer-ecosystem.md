# 卷 29 · 开发者生态与集成（Developer Ecosystem & Integrations）

> 产品能否被采纳，取决于**接入成本**：本卷定义 SDK 与版本策略、IDE/CI/Shell 集成、从其他工具导入迁移、插件与技能 Registry、首次使用向导、反馈闭环、统一搜索、深链协议、IM 机器人、数据种子与脱敏工具。
>
> 来源：迭代轮次 2/3（组件与功能缺口）；需求 ID 见卷 00 §5.29（D29 开发者生态与集成）。

---

## 1. 本卷定位

- **解决**：外部怎么用、怎么接、怎么从别处搬过来、怎么找到能力、怎么反馈问题。
- **不解决**：协议本体（卷 01/附录 B）、插件装载与 SPI（卷 18）、市场内容治理（卷 08/18）、分发与更新（卷 28）。
- **边界**：本卷是**接入面**：向开发者提供 SDK 与集成路径，向用户提供导入、向导与搜索。

## 2. 需求与冲突点

| 需求 | 冲突/要点 |
| --- | --- |
| SDK 多语言 | 覆盖广度 vs 维护成本 → 官方两语言首发 + 社区语言走规范 |
| IDE 集成深度 | 深度（内联编辑）体验好 vs 与内核重复 → 复用协议面，不重写 Agent |
| 导入迁移 | 保真度 vs 语义差异（其他工具的配置无法 1:1 映射）→ 分级映射 + 冲突报告 |
| Registry | 自建 vs 托管 vs 镜像 → 自建优先（企业可离线） |
| 统一搜索 | 全量索引成本 vs 检索体验 → 复用已有索引 + 权限前置过滤 |
| 深链安全 | 便利（`oc://` 一键打开）vs 钓鱼风险 → 签名/确认 + 白名单动作 |

## 4. 选定方案详设

### 4.1 SDK 面设计

| 能力 | 说明 |
| --- | --- |
| 连接 | 本地（stdio/回环 WS）与远程（HTTPS/WSS）；认证（API Key/OAuth/mTLS，卷 23） |
| 会话 | 创建/发送/流式订阅/中断/插话/审批响应（与附录 B.2 一致） |
| 任务与目标 | 提交、查询、事件订阅、取消（与卷 15 一致） |
| 类型 | 由契约生成（类型 + 错误码 + 事件 Payload）；不手写双份 |
| 工具与扩展 | 注册外部工具（经插件或 MCP，不绕过管线）、订阅事件 |
| 测试夹具 | 假模型 + 内存内核 + 断言助手（离线单测 Agent 集成） |
| 示例库 | 每能力一个最小可运行示例（CI 校验可运行） |

**发布物**：TS（npm）、Java（Maven Central 或私仓）、协议规范（OpenAPI + JSON-RPC schema + 事件 Schema）。

### 4.2 IDE 集成能力矩阵

| 能力 | VS Code | JetBrains | Neovim | Zed |
| --- | --- | --- | --- | --- |
| 会话面板 | ✔ | ✔ | ✔（TUI 内嵌） | ✔ |
| 审批（含 diff） | ✔ | ✔ | ✔ | ✔ |
| 内联 diff 应用 | ✔ | ✔ | 部分 | 部分 |
| @ 引用文件/符号/知识 | ✔ | ✔ | ✔ | ✔ |
| 引用跳转（知识/记忆） | ✔ | ✔ | 部分 | 部分 |
| 诊断（装配/插件健康） | ✔ | ✔ | ✖ | ✖ |
| 建议（LSP 式） | 渐进 | 渐进 | ✖ | ✖ |

**原则**：IDE 插件是**协议面的瘦客户端**；不得内嵌 Agent 逻辑（避免双实现漂移）。

### 4.3 CI 集成

| 项 | 设计 |
| --- | --- |
| 容器镜像 | 固定入口 `oc run --json`；镜像内置 JRE 与基础沙箱依赖；镜像签名 |
| 流水线片段 | GitHub Actions（Action）、GitLab CI（include 模板）、Jenkins（共享库片段） |
| headless 命令 | `oc run`（一次性）/`oc task run`（任务）/`oc review --diff`（审查）；全部支持 `--json` 与退出码语义（0 成功 / 1 需人工 / 2 失败） |
| 输出 | JSON（结构化）、SARIF（代码问题，供平台展示）、Markdown（评论体） |
| 权限 | CI 场景默认 `readonly` 或受限写（指定分支/路径）；需显式声明 |
| 成本 | 预算上限必填（防流水线失控）；超限即停并报告 |

### 4.4 导入迁移（`oc import`）

| 来源 | 导入内容 | 映射策略 | 保真度 |
| --- | --- | --- | --- |
| AGENTS.md / CLAUDE.md / .cursorrules 等指令文件 | 项目指令 | 映射为「项目指令（S3）」；多文件按目录层级拆分为分层指令 | 高（语义保留，结构重排） |
| MCP 配置（各家 JSON） | MCP 服务器定义 | 映射为标准 `McpServer` 配置；密钥转为凭证引用（需用户补值） | 高 |
| 模型/端点配置 | Provider 与路由 | 映射为 Provider + 路由规则；密钥引用化 | 中（路由语义不同） |
| IDE 设置 | 快捷键/主题 | 映射为桌面端键位与主题偏好 | 中 |
| 插件/技能清单 | 能力清单 | 生成「替代建议报告」（原生能力 / 市场技能 / 暂不支持） | 中（报告驱动） |
| 会话导出包 | 会话历史 | 解析为导入包（卷 19 §4.4 格式）；不支持格式则仅导入摘要 | 低—高（视格式） |

**规则**：导入必须产出**迁移报告**（成功项 / 需人工确认项 / 不支持项 + 建议）；不得静默丢弃；凭证只导入引用与提示，不导入明文。

### 4.4.1 迁出能力（数据可携带性，产品铁律 10）

| 迁出目标 | 支持方式 | 保真度 |
| --- | --- | --- |
| 通用存档 | 导出包（卷 19 §4.4）：事件 + 任务 + 记忆 + 提示词 + 引用 | 高（完整可复原） |
| 其他 Coding Agent / Harness | 导出「移植包」：项目指令（Markdown）、MCP 配置（标准 JSON）、会话摘要（Markdown/JSONL）、任务与计划（JSON）、技能（Markdown + 资源） | 中（语义保留，工具绑定需重配） |
| 代码与产物 | 标准 Git 仓库 + 工件引用（无需迁移） | 完整 |
| 知识与索引 | 原始文档导出 + 索引元数据（向量不可移植，需重建） | 中（需重建索引） |
| 审计与计量 | CSV/Parquet 导出（合规） | 完整 |

**规则**：迁出不需要管理员审批（用户对自己数据有完全处置权）；导出内容默认脱敏（凭证永不导出）；提供「迁出检查清单」（对方需要哪些文件、如何导入）。**目的**：消除「被锁定」顾虑，让采纳决策无风险。

### 4.5 Registry 服务

| 能力 | 说明 |
| --- | --- |
| 索引 | 插件/技能/团队模板的元数据索引（名称、描述、标签、版本、签名、评分、安装量、兼容矩阵） |
| 下载 | 制品（含签名与校验和）；支持断点续传与私有镜像 |
| 搜索 | 关键词 + 标签 + 兼容性过滤（内核版本/协议版本） |
| 评分与评论 | 需登录与安装记录（防刷）；支持举报与下架 |
| 治理 | 自动扫描（恶意模式、权限声明异常）+ 人工抽检 + 下架（含已安装用户通知） |
| 企业模式 | 私仓（离线镜像包 + 定期同步）；可禁用公共源 |
| API | 供 CLI/桌面端/CI 使用；支持镜像同步与审计 |

### 4.6 首次使用向导（`oc init` / 桌面向导）

```mermaid
flowchart LR
  A["开始"] --> B["环境探测 语言/工具链/容器运行时/Git"]
  B --> C["选择模型来源 官方端点 / 私有端点 / 本地模型"]
  C --> D["凭证配置 引用化 + 连通性测试"]
  D --> E["导入迁移（可选） AGENTS.md / MCP / 其他工具配置"]
  E --> F["选择工作区（当前目录 / 克隆仓库 / SSH / 容器）"]
  F --> G["权限模式与沙箱档建议（含解释）"]
  G --> H["预置技能与插件建议（按探测到的语言栈）"]
  H --> I["示例任务：读代码 → 回答架构问题（验证闭环）"]
  I --> J["完成 输出诊断摘要与下一步建议"]
```

**要求**：全流程可跳过；每步有「为什么需要」解释；失败可重试且保留已填内容；结束输出可直接复制的命令。

### 4.7 统一搜索

| 维度 | 设计 |
| --- | --- |
| 数据源 | 会话（含消息与结论）、任务/目标/团队、知识（文档/代码/知识页）、记忆、插件/技能、工作区文件路径 |
| 索引 | 复用卷 11 索引 + 会话/任务投影；增量更新 |
| 权限 | **前置过滤**（租户/项目/可见范围），与卷 11 一致；跨租户零泄漏 |
| 排序 | 相关度（混合）+ 时效 + 类型权重；可切换排序 |
| 动作 | 打开、作为上下文引用（`@`）、复制链接（深链）、导出 |
| 性能 | P95 ≤ 300ms（与 NFR-P-8 对齐）；结果分页 cursor |

### 4.8 深链协议（`oc://`）

| 动作 | 参数 | 安全 |
| --- | --- | --- |
| `open/session/{id}` | sessionId | 仅打开已授权会话；未授权提示 |
| `open/task/{id}` / `open/goal/{id}` | id | 同上 |
| `approve/{approvalId}` | approvalId + `sig`（签名，短时效） | 签名校验；过期或不匹配拒绝；**打开后仍需用户确认**（防钓鱼一键批准） |
| `open/kb/{docId}` / `open/wiki/{pageId}` | id | 权限校验 |
| `new?prompt=...` | 提示词（长度限制 + 转义） | 仅预填，不自动执行 |
| `install/{plugin|skill}/{id}@v` | id + version | 打开安装确认页（不自动安装） |

**规则**：全部动作白名单；未安装客户端时由官网/文档引导安装；参数一律转义与长度限制；审批类深链**必须二次确认**。

## 7. 非功能设计

- **性能**：SDK 连接建立 ≤ 300ms（本地）/ ≤ 800ms（远程）；向导 ≤ 5 分钟（可跳过）；搜索 P95 ≤ 300ms。
- **可靠性**：导入失败可回滚（导入前快照）；Registry 不可用时本地缓存可用；IM 指令失败给出明确错误。
- **安全**：深链白名单 + 签名 + 二次确认；导入不落明文凭证；SDK 认证与卷 23 一致；IM 身份绑定。
- **可维护**：SDK 生成物入库 + CI 校验一致；IDE 插件为瘦客户端（协议变更自动适配）；导入器按来源独立版本化。
- **可移植**：SDK 与导入器跨平台（Windows/macOS/Linux）。
