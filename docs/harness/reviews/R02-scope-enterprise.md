## 三、专项核查结论（R02 指定重点）

| 项 | 结论 |
| --- | --- |
| 25 · 多租户隔离证明 + 审计防篡改 | **达成**：隔离以三条可测不变量（持久层强注租户条件 / Key 工厂首参恒 tenantId / 检索前置过滤）落地为 CI 对抗用例集 4 组，任一「通过」即阻断发布；防篡改给出哈希公式、锚点链、**可证明边界**（单行篡改必被定位；绕过应用重算的攻击窗口 = 锚定间隔上界 60min）与双校验路径（REST verify + 离线 CLI 同结论） |
| 26 · fail-closed vs fail-open 对账 | **达成**：「闸门失能默认不放行高消耗 / 计量失败永不阻塞主流程」两性显式并列，给出对账收敛公式与偏差上界、三级证明责任（压测无超卖 / 注入不阻塞且缺口可见 / 双故障后一个对账周期内方差比 ≤1%） |
| 27 · 注入检测规则集完整性与误报策略 | **达成**：六家族逐一锚定语法/AST 面（IFS/引号编码/heredoc 替换/危险 flag/畸形 token/方言），完备性门禁 = 语料 ≥150 条且每家族 ≥12 条 + 未覆盖 AST 节点清单非空即告警；误报分三层（硬拦截仅收确定性模式 / 不确定转审批且可回写会话级允许 / 解析失败 fail-closed），硬拦截误报率 ≤0.5% 超限自动降级为 ESCALATE |
| 28 · 反降级 vs 企业钉扎仲裁 | **达成**：固定优先级（安全补丁 > 防降级 > 企业锁定 > 通道偏好）+ **7 例仲裁矩阵**（锁定内安全补丁放行、锁外版本拒绝、nightly 回指拦截、紧急回退票据、同版重装、跨大版本门槛、私仓验签根不符），矩阵即单测清单与 `oc update explain` 口径 |
| 30 · 交互状态机完备性 | **达成**：六态（空/加载/错误/权限/离线/超长）逐界面族 9×6=54 格矩阵补齐文案键与主行动；超长态给出阈值（虚拟滚动 10000 条、diff 2000 行、DAG 200 节点、看板降采样）；矩阵即埋点覆盖表（`ui.state.changed{surface,state}`） |
| 33 · 回放确定性跨平台 | **达成**：新增第 11 条锁定五类非确定性源（路径 POSIX 归一 / UTF-8+LF 与 `.gitattributes` / virtualClock 与禁 `Instant.now()` 架构断言 / 集合序与 JSON 键序 / locale-UTC-`\n` 固定），验证 = 三平台 + CI 容器四份 SHA-256 摘要一致，不一致即阻断；`seed` 必须入 `RunIdentity` |
| 35 · 实验毕业/退出标准 | **达成**：五级转换量化表（PILOT→BETA 成功率 p≤0.05、成本 ≤110%、样本 ≥200 任务/50 用户、14 天窗口；BETA→GA +5pp、≥1000 任务/200 用户、30 天窗口；GA→DEPRECATED 90 天公告；任一态→DROPPED 条件）+ 统计口径（z 检验、每臂 200 样本、样本不足 `ready=false`）+ Guardrail（越权/外泄/P0 = 0） |
