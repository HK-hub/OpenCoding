# 卷 32 · 运维手册与演练（Operations Runbook & Drills）

> 卷 24 定义「装什么、怎么升」，本卷回答**「出事了按哪一页做」**：SLO 与燃尽、告警规则清单、Runbook 条目、故障演练脚本、容量水位操作、升级与回滚手册、值班与升级路径、故障复盘模板。
>
> 来源：迭代轮次 13；需求 ID 见卷 00 §5.32（D32 运维手册）。

---

## 1. 本卷定位

- **解决**：可执行的运维动作（谁、什么时候、按什么步骤、预期结果、失败怎么退）。
- **不解决**：可观测技术栈（卷 24 §4.2）、容量模型（卷 31）、部署形态（卷 24 §4.5）。
- **边界**：Runbook 必须**可直接照做**（命令级）；不可执行的内容（原理说明）归各设计卷。

## 2. SLO 与燃尽（D-OPS-1）

| SLO | 目标 | 窗口 | 燃尽告警（快/慢） | 违反处置 |
| --- | --- | --- | --- | --- |
| 协议面可用性 | 99.9% | 30 天 | 2h 内消耗 5% 预算 / 6h 内消耗 2% | 冻结发布 + 降级非关键功能 |
| 首 token 延迟 P95 | ≤ 1.5s | 7 天 | 同上比例 | 路由降级 + 容量扩容 |
| 事件写入 P95 | ≤ 10ms | 7 天 | — | 检查存储水位与消费者滞后 |
| 会话恢复成功率 | ≥ 99.5% | 30 天 | — | 检查检查点与快照链路 |
| 任务完成率（在线） | ≥ 基线 | 7 天 | 下降 > 5% | 结合模型/提示词变更排查 |

**原则**：SLO 违反 → 停止发布（冻结）→ 归因 → 修复 → 复盘；**不允许**通过下调目标来「修复」。

## 3. 告警规则清单（D-OPS-2）

| 级别 | 规则 | 阈值 | 处置入口 |
| --- | --- | --- | --- |
| P0 页面 | 协议面错误率 | > 5% 持续 5min | RB-01 服务不可用 |
| P0 | 事件写入失败 | > 1% 持续 5min | RB-02 事件链路故障 |
| P0 | 数据库不可用 / 主从切换 | 探活失败 ≥ 3 次 | RB-03 数据库故障 |
| P0 | 存储水位 | ≥ 90% | RB-04 磁盘压力 |
| P0 | 安全事件（SEV1/2） | 触发即报 | RB-09 安全事件响应 |
| P1 通知 | 消费者滞后 | > 60s P95 | RB-05 消费者滞后 |
| P1 | 模型错误率（某端点） | > 10% | RB-06 模型端点异常 |
| P1 | 沙箱不可用率 | > 20% | RB-07 沙箱降级 |
| P1 | 成本异常 | 日成本 > 基线 ×1.5 | RB-08 成本异常 |
| P1 | 审批积压 | 超时审批 > 20/小时 | RB-10 审批积压 |
| P2 工单 | 索引滞后 | > 30s | 常规 |
| P2 | 插件熔断 | 任一插件熔断 | 常规 |

**要求**：每条规则必须有唯一 Runbook ID、执行人角色、验证命令、成功判据。

## 4. Runbook 条目（D-OPS-3）

### RB-01 协议面不可用

| 步 | 动作 | 命令 / 位置 | 预期 |
| --- | --- | --- | --- |
| 1 | 确认影响面 | `oc doctor --remote <endpoint>` / 健康检查 | 明确 500 / 超时 / 证书 |
| 2 | 查看最近变更 | 发布系统最近 2 小时发布记录 | 定位可疑变更 |
| 3 | 快速回滚（若相关） | 按卷 28 §4.2 回滚流程 | 5 分钟内恢复 |
| 4 | 若否：检查依赖 | DB/Redis/对象存储探活 | 定位依赖故障 |
| 5 | 降级（必要时） | 关闭非关键功能开关（特性开关中心） | 保人工会话可用 |
| 6 | 通告 | 状态页 + 客户通知模板 | 用户知情 |
| 7 | 复盘 | 使用 §6 模板 | 产出改进项 |

### RB-04 磁盘压力（水位 ≥ 90%）

| 步 | 动作 | 说明 |
| --- | --- | --- |
| 1 | 定位增长源 | 事件表分区 / 快照 / 媒体 / 日志 分类统计 |
| 2 | 立即缓解 | 触发归档（冷迁移）、清理过期遥测、清理本地缓存与旧版本包 |
| 3 | 保护写入 | 若仍 > 95%：阻断高成本新任务，保人工会话 |
| 4 | 扩容 | 扩存储或增加分区（滚动执行） |
| 5 | 复核 | 水位回落到 < 75% 且 24h 无反弹 |

### RB-05 消费者滞后

| 步 | 动作 |
| --- | --- |
| 1 | 确认消费者（投影/审计/计量/前端推送）与滞后量 |
| 2 | 检查错误日志（死信、Schema 拒绝、权限错误） |
| 3 | 提升消费者并发（受限内）或暂停非关键消费者（遥测优先让路） |
| 4 | 死信重放（按卷 16 §4.4）；Schema 拒绝需修复生产者 |
| 5 | 验证：滞后 < 10s 持续 10 分钟 |

### RB-06 模型端点异常

| 步 | 动作 |
| --- | --- |
| 1 | 区分端点故障 vs 网络/凭证（`oc doctor model <provider>`） |
| 2 | 若凭证：轮换/刷新（卷 30 §4.2） |
| 3 | 若端点：路由切换到备选（规则路由的显式回退链）并通告（降级事件） |
| 4 | 若配额：切换凭证/申请提额；预算告警联动（卷 31） |
| 5 | 验证：错误率回落，成本变化可解释 |

### RB-07 沙箱降级

| 步 | 动作 |
| --- | --- |
| 1 | 确认不可用档位（L1 容器运行时/L2 微虚拟机） |
| 2 | 策略降级：允许的档位下移到 L0+（企业若禁止 → 阻断执行并通告） |
| 3 | 平台修复（容器运行时重启/镜像拉取失败排查） |
| 4 | 恢复后回切，并复核降级期间的执行审计（是否有越界尝试） |

### RB-09 安全事件响应

见卷 30 §4.7（SEV 分级）+ 本卷 §6 复盘模板；冻结/吊销/取证/通告四步必须在 Runbook 中固化为命令序列。

### RB-10 审批积压

| 步 | 动作 |
| --- | --- |
| 1 | 确认积压来源（单用户/单团队/系统性问题） |
| 2 | 通知审批人（IM/邮件）+ 升级路径（卷 06 D-PERM-8） |
| 3 | 若为规则缺陷：临时放宽低风险自动批准规则（记录 + 事后复核） |
| 4 | 复核：积压 < 阈值且审批延迟回到基线 |

### RB-11 模型厂商下线/涨价/服务降级

| 步 | 动作 | 说明 |
| --- | --- | --- |
| 1 | 影响面盘点 | 受影响模型/凭证/项目/自动化模板（`oc model impact <provider>`） |
| 2 | 路由切换 | 启用备选模型（规则路由回退链，卷 02 D-MDL-6）；生成降级事件与用户通告 |
| 3 | 能力校验 | 备选模型是否满足所需能力位（tools/vision/thinking/结构化输出）；不满足则显式报错而非静默降级 |
| 4 | 成本重估 | 新价目下重算预算与配额（卷 31 §4.2）；必要时收紧默认路由档 |
| 5 | 长任务处理 | 进行中任务：暂停并保存检查点，切换后从检查点续跑 |
| 6 | 复评与沉淀 | 更新模型目录与路由基线；把「供应商退出」写入风险评估与演练计划 |

### RB-12 极端组合场景预案

> 单点故障按前 11 条 Runbook；**并发多故障**按本条降级顺序执行（保命 → 保数据 → 保体验）。

| 场景 | 首要动作 | 降级顺序 | 恢复判据 |
| --- | --- | --- | --- |
| 数据库不可用 + 磁盘水位 ≥ 90% | 阻断所有写入型与高成本任务，仅保人工只读会话 | ① 只读模式 ② 停止索引/遥测 ③ 停止自治任务与模板 | 数据库恢复且水位 < 80% |
| 模型全端点不可用 | 进入「离线协作」模式（无模型） | ① 读取/搜索/编辑可用 ② 计划与任务编辑可用 ③ 审批可用（由人执行命令） | 至少一个端点恢复 |
| 断网 24h（企业出口故障） | 切换 air-gapped 行为（禁用外发、缓存元数据） | ① 本地模型端点（若有）② 无模型只读 ③ 后续凭导出包同步 | 出口恢复 + 事件补传完成 |
| 超长任务（> 7 天） | 检查点频率提升、心跳与汇报加频 | ① 关停非关键同步类任务 ② 提高检查点密度（≤ 10 分钟） | 任务正常推进且成本在预算内 |
| 时钟漂移（节点间 > 5s） | 停止依赖时间的判定（cron/超时） | ① 用逻辑时钟推进 ② 调度暂停直到 NTP 同步 | 漂移 < 1s |
| 恶意仓库/巨型单文件 | 阻断工具执行，隔离该工作区 | ① 只读检查 ② 索引跳过该文件（记录）③ 人工确认后放行 | 人工确认 + 资源回落 |
| 租户级异常消耗（可能被滥用） | 熔断该租户自治任务与模板 | ① 限流 ② 通知管理员 ③ 安全复核（卷 30 §4.8） | 复核通过 + 用量回到基线 |

## 5. 故障演练（D-OPS-4）

| 演练 | 频率 | 脚本要点 | 成功判据 |
| --- | --- | --- | --- |
| 数据库主从切换 | 季度 | 注入主库故障 → 观察自动切换 | RTO ≤ 5min；无数据丢失（RPO 0） |
| 进程被杀恢复 | 月度 | `kill -9` 内核进程 → 重启 | 未完成会话恢复到检查点；无重复副作用 |
| 网络分区（模型端点） | 季度 | 阻断模型出网 10 分钟 | 熔断 + 降级 + 恢复后自愈 |
| 磁盘打满 | 季度 | 填充至 95% | RB-04 全流程；核心写入不受损 |
| 沙箱崩溃 | 月度 | 杀掉沙箱运行时 | 任务失败隔离；其他会话无感 |
| 更新失败回滚 | 每版本 | 注入更新包损坏 | 自动回滚 ≤ 2min |
| 恢复演练（备份） | 季度 | 从备份 + WAL 恢复到指定时间点 | RTO ≤ 15min；一致性校验通过 |
| 安全桌面演练 | 季度 | SEV2 场景推演（无实际破坏） | 四角色到位；动作正确；复盘产出改进项 |
| 容量水位演练 | 半年 | 压测至 80% 水位 | 告警正确；降级策略生效 |

**要求**：每次演练产出**报告**（时间线、动作、偏差、改进项）；改进项进入卷 26 反馈闭环并跟踪关闭。

## 6. 复盘模板（D-OPS-5）

| 段 | 内容 |
| --- | --- |
| 摘要 | 一句话：发生了什么、影响、持续时长 |
| 时间线 | 检测 → 定位 → 缓解 → 恢复（精确到分钟，含命令） |
| 影响面 | 租户/用户/任务/数据/成本 |
| 根因 | 直接原因 + 系统性原因（设计/流程/测试缺口） |
| 做得好 | 有效机制（保留） |
| 待改进 | 每项：动作、责任人、截止时间、验证方式 |
| 数据 | 相关指标与事件 ID（可复核） |

**硬性规则**：不允许「加强意识」类空改进项；每条改进必须落到**代码/配置/测试/文档**四类之一。

## 7. 值班与升级（D-OPS-6）

| 项 | 约定 |
| --- | --- |
| 值班轮次 | 周为单位，主副班（避免单点） |
| 升级路径 | 值班 → 领域负责人（15 分钟未缓解）→ 架构/安全负责人（30 分钟）→ 管理层（1 小时，P0） |
| 交接 | 交接单（未闭环告警、进行中事件、待观察变更） |
| 免打扰 | 非 P0 告警默认在工作时段处理；P0 全天候 |
| 权限 | 值班具备：回滚、开关、限流、冻结、扩容 五类操作权限（其余需审批） |

## 8. 容量水位操作（D-OPS-7）

| 水位 | 动作 |
| --- | --- |
| < 60% | 正常；可执行扩容预留 |
| 60–80% | 规划扩容（本季度）；检查增长趋势 |
| 80–90% | 告警；冻结非关键新增大对象；提前执行归档 |
| ≥ 90% | 阻断高成本新任务；紧急扩容；必要时降级（遥测采样降级、索引延迟更新） |

## 9. 完成定义（DoD）

- [ ] SLO 与燃尽告警配置完成（含快/慢燃尽）。
- [ ] 告警规则清单 ≥ 12 条，每条有唯一 Runbook ID 与验证命令。
- [ ] Runbook ≥ 10 条，实机验证过（至少 RB-01/03/04/05/06 五条）。
- [ ] 九类故障演练各执行一次并产出报告；改进项全部闭环。
- [ ] 复盘模板产出 ≥ 2 份真实复盘（含改进项落地证据）。
- [ ] 值班与升级路径文档化；五类操作权限落实到角色。
- [ ] 容量水位四级操作在实际水位告警时被验证过。

## 11. 开放问题与默认决策

| 项 | 默认决策 |
| --- | --- |
| 状态页 | 企业版默认提供内网状态页；社区版仅公告 |
| 演练影响生产 | 默认在生产低峰演练；破坏性演练在预发环境 |
| 值班范围 | 默认覆盖 P0/P1；P2 工单化 |
| 复盘时限 | P0 事件 3 个工作日内出复盘 |
| 改进项跟踪 | 纳入研发看板，超期升级 |
