# 卷 35 · 智能增强包（AI Enhancement Pack）

> 本卷把「模型能力」包装成**产品化特性**：PR 描述生成、变更日志、审查机器人、测试生成、Flaky 检测、文档漂移、Standup 汇总、代码库问答、代码迁移助手、事故时间线、四类智能检测。共性约束：**AI 生成必须可标注、可追溯、可校订、不自动合并**。
>
> 来源：迭代轮次 9；需求 ID 见卷 00 §5.35（D35 智能增强包）。

---

## 1. 本卷定位

- **解决**：把「模型能做但用户要手动做」的事变成一键/自动能力，并保证质量与安全边界。
- **不解决**：任务编排与触发（卷 14/15/34）、审查流程与合并门禁（卷 21）、评测（卷 26）。
- **边界**：本卷特性**复用**卷 05 工具、卷 11 检索、卷 12 内核、卷 34 模板；不引入新的执行链路。

## 2. 共性约束（D-AI-0，全部特性适用）

| 约束 | 说明 |
| --- | --- |
| 标注 | 所有 AI 生成物必须显式标注「AI 生成」并提供模型与提示词版本（可追溯） |
| 可校订 | 生成物一律**草稿**形态，人类可编辑后提交；不得直接覆盖人类已有内容（冲突时并排展示） |
| 不自动合并 | 涉及代码/配置的产出只提 PR，合并不由 AI 决定（卷 34 §5） |
| 引用强制 | 结论类输出必须带来源引用（文件/行/提交/事件），无引用标注「推断」 |
| 成本可见 | 每次运行报告成本；超预算即停（卷 31） |
| 权限最小 | 默认只读；需要写入时按能力声明与预授权（卷 06） |
| 质量度量 | 采纳率、误报率、节省时长三项必须可查（卷 26 §4.1 在线指标） |

## 3. 设计空间（M×N）

| ID | 主题 | 选定 | 被放弃分支与理由 |
| --- | --- | --- | --- |
| D-AI-1 | 特性组织 | **双形态：内联（在会话/审查流中即时可用）+ 命令（`oc ai <verb>` / 模板步骤）** | 仅命令（发现性差） |
| D-AI-2 | PR 描述生成 | **变更驱动 + 模板约束（含验收与测试证据）**，并附「未覆盖项」提示 | 纯模板填空（无信息量） |
| D-AI-3 | 变更日志/发布说明 | **提交分类 + 语义 diff 双源 + 人工校对门**（breaking 必须人工确认） | 纯提交分类（漏语义变更） |
| D-AI-4 | 审查机器人 | **规则优先（确定性高）+ 模型补充（语义/设计问题）+ 置信度标注** | 纯模型（误报高） |
| D-AI-5 | 测试生成 | **变更驱动 + 覆盖率缺口驱动；属性测试用于纯函数；生成即运行验证** | 无验证生成（垃圾用例） |
| D-AI-6 | Flaky 检测 | **重跑判定 + 统计（同用例跨运行方差）+ 隔离运行（依赖外部资源标记）** | 单次失败即标记（误判） |
| D-AI-7 | 文档漂移检测 | **代码符号/API 提取 vs 文档声明比对 + 语义检索补充** | 纯检索（漏结构化差异） |
| D-AI-8 | Standup/周报 | **事件与任务聚合（客观）+ 摘要（主观，标注）+ 环比** | 纯模型编（不可信） |
| D-AI-9 | 代码库问答 | **RAG + 强制引用 + 「未找到依据」明确回答** | 无引用自由回答（幻觉） |
| D-AI-10 | 代码迁移助手 | **规格驱动 + 小步批次 + 每批验证（构建/测试）+ 断点续跑** | 一次性大改（不可控） |
| D-AI-11 | 事故时间线 | **事件/变更/告警多源聚合 + 去重 + 因果标注（相关≠因果）** | 单源（信息不全） |
| D-AI-12 | 智能检测 | **四类：性能回归、依赖风险、配置漂移、安全模式（均带基线对比与阈值）** | 无基线检测（噪声） |

## 4. 特性详设

### 4.1 PR 描述生成

| 项 | 设计 |
| --- | --- |
| 输入 | 分支 diff、提交列表、任务/计划引用、测试证据、审查评论 |
| 输出 | 结构化描述：变更摘要 / 动机 / 影响面 / 验证方式（含证据）/ 风险与回滚 / 未覆盖项 |
| 权限 | 只读 + 写 PR 描述（不外发代码内容，除模型调用） |
| 质量 | 引用强制（每条摘要指向文件/提交）；「未覆盖项」非空则高亮 |
| 采纳度量 | 描述被直接使用比例、被编辑比例 |

### 4.2 变更日志与发布说明

| 项 | 设计 |
| --- | --- |
| 双源 | 提交分类（Conventional Commits，卷 21 §4.2 尾注）+ 语义 diff（接口/行为变化） |
| 分类 | feat / fix / perf / refactor / breaking / security / docs / internal |
| 门 | **breaking 与 security 条目必须人工确认**；缺失变更类型标记「未分类」 |
| 输出 | 双语 CHANGELOG 条目 + 发布说明（含升级指引与迁移命令） |
| 版本建议 | 语义化版本建议（含 breaking → major），人工最终决定 |

### 4.3 审查机器人

| 检查类 | 规则（确定性） | 模型补充（语义） |
| --- | --- | --- |
| 风格/格式 | 格式化、命名、导入顺序 | — |
| 正确性 | 空指针模式、未处理错误、边界 | 逻辑漏洞、竞态、错误处理缺失 |
| 测试 | 新逻辑无测试、断言缺失 | 测试是否真正覆盖意图 |
| 安全 | 密钥模式、注入模式、危险 API | 权限绕过、越权访问设计 |
| 设计 | 循环依赖、分层违规 | 抽象泄漏、职责混乱 |
| 输出 | SARIF + 内联评论；每条带置信度（高/中/低）与依据 | 低置信度默认折叠 |

**规则**：低置信度不阻塞合并；高置信度安全问题可请求变更（但仍需人工确认）；误报可通过反馈学习（进入评测用例）。

### 4.4 测试生成

| 项 | 设计 |
| --- | --- |
| 触发 | 手动 / 覆盖率缺口 / 变更驱动（新函数无测试） |
| 策略 | 单元（边界值 + 异常路径）/ 集成（关键链路）/ 属性测试（纯函数不变量） |
| 验证 | **生成即运行**：不通过则丢弃并报告；通过后检查是否「假测试」（无断言/恒真） |
| 输出 | 测试 PR + 覆盖率变化 + 未覆盖残余说明 |
| 度量 | 生成的测试通过率、被保留比例、覆盖率提升幅度 |

### 4.5 Flaky 测试治理

| 项 | 设计 |
| --- | --- |
| 数据源 | 测试事件（含重跑）、执行环境信息、历史方差 |
| 判定 | 同一提交重跑结果不一致 / 跨运行方差超阈值 / 隔离运行后稳定（归因外部依赖） |
| 归因 | 时序（sleep/时钟）、网络、共享状态、随机、资源竞争、测试顺序依赖 |
| 输出 | 观察清单（低置信）+ 修复 PR（高置信，仅低风险改动）+ 隔离建议（标记 quarantined） |
| 度量 | flaky 数量趋势、平均修复时长 |

### 4.6 文档漂移检测

| 项 | 设计 |
| --- | --- |
| 源 | 代码（公开 API/配置项/CLI 命令/环境变量）+ 文档（README/docs/知识页） |
| 比对 | 结构化提取（符号/参数/默认值）vs 文档声明 → 差异清单（缺失/过时/多余） |
| 输出 | 报告 + 修订 PR（仅文档目录）+ 文档所有者通知 |
| 度量 | 漂移项数量趋势、修复率 |

### 4.7 Standup / 周报汇总

| 项 | 设计 |
| --- | --- |
| 客观部分 | 任务状态变化、提交、PR、审查、事故、自动化收益（全部来自事件，不可编造） |
| 主观部分 | 摘要与风险提示（标注为 AI 生成） |
| 输出 | Markdown / 邮件 / IM；含环比与「需要关注」清单 |
| 度量 | 阅读率、被引用次数、用户评分 |

### 4.8 代码库问答（只读）

| 项 | 设计 |
| --- | --- |
| 检索 | 卷 11 三路混合 + 符号图 |
| 回答 | 强制引用（文件+行/文档+版本）；无依据时明确回答「未找到依据」并给出检索范围 |
| 权限 | 严格继承用户权限（含文档 ACL 与租户隔离） |
| 输出 | 回答 + 引用列表 + 可「作为上下文引用」进入会话 |
| 度量 | 引用打开率、追问率、满意度 |

### 4.9 代码迁移助手

| 项 | 设计 |
| --- | --- |
| 场景 | 框架升级、语言版本升级、API 弃用替换、测试框架迁移 |
| 流程 | 规格化（规则 + 示例 + 验收）→ 影响面分析（调用点枚举）→ 小批（≤ 50 文件/批）→ 每批构建测试 → 断点续跑 → 总报告 |
| 安全 | 每批独立分支/提交；失败批次回滚不影响已完成批次；不改变公开行为（除非规格要求） |
| 输出 | 分批 PR（可合并为栈式提交，卷 21 D-GIT-4）+ 迁移报告 |
| 度量 | 自动迁移比例、人工干预率、回归率 |

### 4.10 事故时间线生成

| 项 | 设计 |
| --- | --- |
| 数据源 | 事件日志（发布/配置/告警/错误率）、变更记录、审批、通知历史 |
| 输出 | 时间线（精确到分钟）+ 相关性标注（明确「相关≠因果」）+ 数据缺口清单 |
| 用途 | 复盘输入（卷 32 §6）、改进项生成 |
| 禁令 | 不得生成因果结论（仅呈现事实与相关性） |

### 4.11 四类智能检测

| 检测 | 基线 | 触发 | 输出 |
| --- | --- | --- | --- |
| 性能回归 | 历史 P95/基准（卷 26 §4.4） | 超过阈值或趋势劣化 | 报告 + 定位建议（可疑提交/查询） |
| 依赖风险 | 漏洞库 + 维护活跃度 + 许可证白名单 | 新增或恶化 | 报告 + 升级/替代建议 |
| 配置漂移 | 期望配置（`.oc/env.yaml`、IaC、策略） | 与期望不符 | 报告 + 修复 PR（低风险配置） |
| 安全模式 | 安全用例库 + 代码模式 | 命中模式 | 告警 + 修复建议（可能触发红队用例） |

## 7. 非功能设计

- **质量门**：任何生成物进入人类视野前必须通过：结构校验（schema）+ 事实引用检查（引用存在性）+ 安全扫描（含密钥/危险模式）。
- **成本**：默认使用中低成本模型档；单次运行预算上限（如 $2）；批量场景（迁移/覆盖）按批结算。
- **时延**：内联场景（PR 描述生成 ≤ 30s）；批量场景异步 + 进度可查。
- **隐私**：不外发代码内容除声明的模型调用（企业可强制本地模型）；产出中的敏感信息按卷 24 DLP 过滤。
- **可解释**：每条结论可展开「依据」（引用列表 + 使用的规则/模型）。

## 8. 完成定义（DoD）

- [ ] 12 项特性全部可调用（内联 + 命令双形态至少其一），且标注 AI 生成与版本。
- [ ] 共性约束 7 条全部落地并有校验（标注缺失/无引用/直接覆盖人类内容均被拦截）。
- [ ] PR 描述与发布说明：引用覆盖率 ≥ 90%；breaking 必须人工确认（用例）。
- [ ] 审查机器人：规则 + 模型双通道；置信度标注；误报反馈闭环可用。
- [ ] 测试生成：生成即运行；假测试检测生效（无断言用例被拒）。
- [ ] Flaky 检测：三类归因输出；隔离建议可用。
- [ ] 文档漂移：结构化比对可用；修订 PR 仅触及文档目录（用例）。
- [ ] 代码库问答：无依据时明确拒绝回答；引用可打开。
- [ ] 迁移助手：分批 + 每批验证 + 断点续跑（示例迁移跑通）。
- [ ] 事故时间线：多源聚合可用；不生成因果结论（用例校验输出中无因果断言）。
- [ ] 四类智能检测各有一个基线场景跑通（含阈值与报告）。
- [ ] 采纳率/误报率/节省时长三项指标可查并进入看板。

## 10. 开放问题与默认决策

| 项 | 默认决策 |
| --- | --- |
| 默认启用特性 | 仅 PR 描述与审查机器人默认开启（可在向导关闭） |
| 增强使用的模型档 | 默认中低成本档；可配置为与主会话同模型 |
| 迁移批大小 | 默认 ≤ 50 文件/批（可配 10–200） |
| 误报处理 | 反馈进入评测集；同一规则连续误报超阈值自动降级为「建议」 |
| 生成物保留 | 草稿保留 30 天；被采纳的转为正式产出并保留 |
