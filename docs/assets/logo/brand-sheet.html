Open Core — 开口环

一段 296° 的三色环，右上留出 64° 开口，内核朝开口偏移。三件事同时说清：边界是开放的、能力被拆成可替换的模块、Agent 始终在系统中心并且可以走出去。

构成逻辑

  • 开口：环不闭合。任何内容、任何功能都能从这里接入或长出。
  • 三段：Coding / Design / Work 是同一系统的三个可替换模块，不是三个产品。
  • 偏移内核：Agent 不在正中等待，而是朝边界移动——能接管任意环节。
